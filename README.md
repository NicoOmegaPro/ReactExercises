# Ejercicios de React

Ejercicios que hice mientras aprendía React con Vite. Cada carpeta es un proyecto independiente.

## Ejercicios

| Carpeta | Proyecto | Qué practica |
|---------|----------|--------------|
| `react(Netflix)` | Página tipo Netflix | Componentes y estilos con CSS |
| `react2(TiendaZapatos)` | Tienda de zapatos | Componentes y props |
| `react3(BlogViajes)` | Blog de viajes | Componentes y maquetación |
| `react3(BlogViajes) copy` | Blog de viajes (versión ampliada) | React Router y Axios |
| `react4(Instagram)` | Feed tipo Instagram | Estado con `useImmer` |
| `react5(Tours)` | Lista de tours | `useEffect` y `fetch` |
| `react6(Notes)` | Notas | Estado y `localStorage` |
| `react7(BudgetCalculator)` | Calculadora de presupuesto | `useRef` y `localStorage` |
| `react8(Calculadora)` | Calculadora | `useRef` y Math.js |
| `react9examenPrueba(Examen)` | Examen de prueba | `fetch`, `useRef` y `localStorage` |
| `react10(Bitcoins)` | Precios de criptomonedas | API con Axios y Bootstrap |
| `react11(Materiales-casas)` | Materiales de casas | `fetch` y `useImmer` |
| `react12(pelicualasYT)` | Películas con tráiler | `fetch` y vídeos de YouTube |
| `react13(PeliculasApi)` | Buscador de películas | API, React Router y scroll infinito |
| `react14Examen(Quesos)` | Examen: quesos | `fetch` y `useImmer` |
| `react15(dinero)` | Gestión de dinero | `useReducer` y Context |
| `react16(CreateContext)` | Context API | `createContext`, `useContext` y `useRef` |

## Cómo ejecutar uno

```bash
cd "react8(Calculadora)"
npm install
npm run dev
```
